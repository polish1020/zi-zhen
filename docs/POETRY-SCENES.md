# 逐句诗境（v11）

109 首诗词的全部 483 条完整五至七字句均已加入手工配置的诗境。源表为 [poetry-signatures.txt](../data/poetry-signatures.txt)，逐句释义、名称、规则和效果为 [完整清单](reports/poetry-scenes.json)。没有仅完成几个示例，也没有用改倍率、目标数或动画名称填充独特性。

## 区分口径

90 类交互规则组合成 483 个诗境程序，每句含两至三项规则。审计将规则去重并排序，忽略所有数字、名称、动画与原有选敌优先级，仍有 483 个不同程序。组合顺序颠倒不算新程序。相近意象可以使用同一条底层规则；这是 483 个不同的句意程序，并非 483 个完全互不复用的底层系统或 483 套全部单独绘制的动画。

| 类别 | 真实交互示例 |
|---|---|
| 水域与道路 | 按停留时间下沉、沿道路移动的瀑流/顺流/逆流、旋涡回拉、过桥援击 |
| 生长与陷阱 | 死亡处生芽、后续敌人踩痕、延迟开花、敌人经过后长出谷刺 |
| 飞行与视野 | 击落后允许地面塔攻击、托起后落地冲击、盘旋协战、登高、超原射程锁敌 |
| 连线与重逢 | 藤蔓拉回领先者、两敌相遇爆发、友塔三角、穿过织网、灯火逐塔接力 |
| 受击与反击 | 三次受击竹节、实际护盾吸收凝珠、霜衣反扑、伤害锤炼破甲、丝茧吸收后化蝶 |
| 友军与掩护 | 真实目标优先级变化、危急诱敌、分担伤害、药香照料、莲叶转移、受伤鼓舞 |
| 观察与时机 | 记录真实伤害后回响、观察三种敌人、记忆阵亡种类、仅蓄力时缄默、离开射程后送别 |
| 临时造物与轮换 | 友塔幻身、废墟旁草木协战体、昼夜轮换、每次施法轮换季节 |

例如“千山鸟飞绝”可使原来打不到飞行怪的石塔参战；“桃花潭水深千尺”的水域停留时间影响减速程度；“飞流直下三千尺”沿真实道路移动。“露似真珠月似弓”将受击凝露、实际护盾凝珠和月照扫光组合；“牵牛织女渡河桥”结合过桥援击与敌人靠近时的相逢触发。

## 战斗、限制与数值

仍由四次普攻蓄满诗韵，沿用各句 12/14/16 秒冷却与全场效果共享间隔。释放时执行原有瞬发起手，再生成 6 秒持续诗境。持续效果不额外充能。暂停时游戏时间不前进；源塔损毁时移除诗境，封禁期间停止其主动持续行为。已经施加的有限时长状态按各自到期时间结束。

普通攻击、基础数值、造价、升级和旧 120,519 个短词配置不变。新开局墨点下限提高到 400：前八章 400、第九章 410、第十章 440；切章和重试同样生效，旧存档保留当前余额。为给持续交互留出伤害预算，原起手专属伤害倍率系数由 1.5 改为 0.9；不缩短控制时间或削减全场支援。一次诗境的持续直接伤害原始预算合计为施法塔攻击的四倍，分配给本句规则；每项规则另有限定修复/护盾预算。破甲、揭示、控制与敌方护盾消磨分别按对应规则结算，不能把它们当作同等生命伤害。伤害仍经过原有护甲、护盾、冰壳、光环与反伤结算。

Boss 击退距离为普通敌人的五分之一，击落持续 0.75 秒（普通飞行怪 3 秒），同目标击落间隔 8 秒；冻结/缄默沿用 Boss 四分之一时长和控制保护。击落保留原生飞行路线与路程，避免突然跳到地面线路。深潭对普通地面怪每层减速 15%、最多 45%，对 Boss 每层 5%；未破冰壳免疫这一阻碍。护盾、攻速、减伤取强不相加。

修复只作用于存活塔；临时协战体不占塔位，不重建废墟，不恢复山门爱心。收获只有真正掉落墨点的击杀才支付，单印记最多 3、整轮最多 10，重复死亡事件不会重复奖励。各规则的等待、次数、连线、敌人记录和预算均有上限；旧事件不会无限积累。

## 表现与说明

持续动画读取实际战斗状态，绘制水域、路线波头、落羽、升风、植物、连线、移动协战体、昼夜/四季、声波与受击符印。普通与减少动态模式均保留能力反馈，不用不透明全屏覆盖。每次施放只为整句显示一次诗境名；击落/下沉状态有对应标识，持续命中有独立反馈。

塔详情、组词详情与词典共用真实规则文案，只列本句两至三项诗境及起手效果、相关限制；不展示系统设计解释。原诗、作者、逐句释义和数字仍可查看。词典嵌套返回保留搜索、筛选、页码、滚动及事件响应。

## 存档与打包

战局版本 v11，兼容 v1—v10。旧牌、已消费墨点、原塔投入/伤势和随机状态保留；旧战局不追补一轮绝技。v11 深拷贝并验证诗境、反应事件、预算、时钟、目标、移动/落地状态；恢复时不重放伤害或奖励。未来版本、未知规则、越界预算、重复规则和非法目标不能通过恢复。

统一静态清单为 40 个资源，网站、Vercel、IGA 准备目录和原生 WebView 本地资源来自同一份源文件。新增四个模块为规则、伤害结算、交互引擎与持续绘制。

## 验证与结果

`node --test tests/*.test.mjs`：463 项通过，包含全部 483 句在真实 `Game.step` 中施放、十章各入口与中途读档，90 类规则分别在满足条件时产生实际效果；另直接断言击落后的地面塔命中、飞行几何、深潭停留/离开、Boss/冰壳抗性、瀑流推进、莲叶转移、延迟来敌、实际护盾凝珠、三击雨盖、远望射程、敌军选塔、废墟协战、收获去重和存档拒绝。

`tests/poetry-scenes.cjs`：Chromium / WebKit，320×568、393×852、667×375、1440×1000。真实运行击落/深潭/瀑流、暂停、刷新、详情与底部按钮；每种浏览器对 483 组诗境在普通和减少动态模式各绘一次（966 次），覆盖全部 90 条规则。另回归旧版诗句建造、扣字/扣费、全诗阅读与词典五种返回路径。WebKit 模拟不是实体 iPhone 硬件验收。

400 局十章主线模拟为 **274/400（68.5%）**，两种原有策略各 200 局，共用种子 1—20，允许损塔，按爱心未耗尽通关计胜；没有超时。原始诗塔版本为 61%，加入诗境、尚未增加初始墨点时为 62.5%，按用户要求将初始墨点提高到至少 400 后为本次 68.5%。没有再修改怪物、路线、奖励、维修价或策略来凑概率。这不是独立的人类玩家胜率；首章样本 40/40，资金更充裕使前期更容易，第五、九章仍有高点，不宣称难度严格单调。
