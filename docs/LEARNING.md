# 普与学：完整词义战斗演绎

原「文」改显示为「普」，保持原基础数值、三/四字第四击效果及轮末额外自修 5%。内部 basic ID 保持兼容。新的 learning 属性显示为「学」，涵盖 1,346 个词，包含全部 736 条学习释义（480 条成语、256 条普通/文化词），另外 610 个常见近义词、日常词及短语。共十五属性。

「学」不是每词独占一段代码。相近词精确归入 43 类有实际机制的招式，不用哈希、随机抽签或单字字根给成语硬套元素。每个词的本义由原学习释义解释；战斗演绎是游戏设计，单独展示，不能作为词典解释。词表见 [LEARNING-WORDS.md](LEARNING-WORDS.md)。

| 画龙点睛 | 明光点睛 | 显形、弱易伤，周期强化一座友塔下一击，不因龙字喷火 |

## 强度与边界

- 学属性字数价格系数与原游戏一致，以基础造价 60、攻击 22、射程 170、间隔 1.05 秒为参照；各招式有自己的倍率和节奏取舍，所有百分比按已经扣除附加词义取舍的面板攻击计算。
- 多段、多目标系数拆分伤害预算；三连发不等于三倍面板伤害。学招式替代通用攻击形态与普属性第四击余波，不叠加三套核心输出。
- 附加词义仍按品质最多 0/1/1/2；精确覆盖优先，学习保留研习、成长保留成长、金蝉脱壳没有生财附加、三顾茅庐没有因茅字产生的缠绕。
- 协同不叠加；受强化出手不能再触发核心协同。鼓舞与其他加速取最强。辅助只找范围内另一座存活词塔；封禁的友塔不接收下一击强化。
- 治疗、护盾的接受者各自有 6 秒间隔；多座同类塔不能靠换施术者刷新它。盾取最大而非相加。辅助没有爱心恢复、无废墟复活。
- 定身、缄默、推退遵守已有同目标间隔和冰壳抗性；Boss 位移减半。迷阵只延后普通攻塔蓄力，不延长大招。既有反弹、抵抗及护军仍正常结算；学属于法术，缄言判官的法术抵抗包含学。
- 生财演绎仅在真实击杀时发赏金，共享既有全场上限；不增加无条件轮末资源。

## 语义检查与纠正

全部 736 条已有释义逐项纳入精确词表；1,346 个学词检查了归组、招式、附加词义与实际代码路径。另修正豆腐误毒、金鱼误生财、银河误生财、土豆误山石、金文误生财、发明误光、地铁误山石等；流星锤改为石系重击，毒镖改为毒系远射，岩浆/熔岩改为火系并带灼热。

全库 107,406 词扫描了唯一性、有效属性、可用形态、有限数值、品质槽位等结构约束；这不等于对全部词逐条完成辞书级语义审订。精选表使用精确完整词名，其他词仍可采用原有词根规则，后续发现的误判可补精确词项。
