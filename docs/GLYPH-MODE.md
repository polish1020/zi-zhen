# 偏旁造物 · 第一版

与组词守关并列的独立入口，地址为 `/glyph.html`。模式选择在首页，造字页也可返回首页切换；塔防的引擎、词库和技能模块与基线 `84b2955` 字节一致。

## 可玩内容

20 个短关卡、60 个任务字、16 个额外发现字，共 76 字、70 个可用部件。字族从青、包、马开始，再逐渐接触木、人、心、草、手、水、口、宝盖头、贝、衣、足等部件。最后一关复习众、品、晶的品字形结构。

左右、上下、包围和三叠四种摆法；门和走的示例标明半包围结构，大口框囗与口分开，国的内部是玉。森支持三个木，也支持木在上、林在下。只确认项目收录的配方；未收录组合提示“还没收进本次工坊”，不会把一个可能存在的字误称为不存在。

孩子点选或拖动部件，拼出字后看拼音、释义，可听系统朗读，再把这个字用在场景里。清净化池水、晴让阳光出现、请邀请伙伴等。每个场景三项任务，可以选择次序；每关还有额外字可探索，完成场景以后仍可自由拼字。字册按关卡收集，记录已认识和已描红的字。

部件可重复使用，没有墨点、爱心、倒计时、失败惩罚和付费提示。成功解决任务才点亮叶子；反复拼同一个字不会重复增加任务进度。前一关完成后开放下一关，已开放的关卡随时可选。

## 写一写

76 个字都提供本地笔画数据，共 625 笔。可以逐笔看示范，再从亮点出发沿轮廓描红。检查起笔、方向、终点和路径，容许一定手部偏差；不是任意手写字符识别，也不承诺书法评分。

看示范和失败尝试不会记为完成；按顺序实际描完全部笔画才记录一次。中途关闭、重看或重写会清理计时与指针状态，离开弹窗不自动记成练习。笔顺数据加载失败可重试，仍能继续组字。

朗读依赖浏览器和操作系统的中文语音。界面始终显示拼音和释义，不使用外部语音服务或录音。

## 进度与手机

造字进度单独保存在 `wordward-glyph-save-v1`，包含关卡、已解决任务、认识的字、描红次数和当前部件草稿。造字页只写自己的进度与朗读偏好，切回塔防保留原战局、怪物、字牌和墨点。当前仍是本机浏览器存档，没有云同步。

手机竖屏上方为场景，下方为造字台；横屏为左右排列。游玩界面保持一屏，关卡页和字册可滚动，描红使用独立弹窗。支持点选与拖动，禁用误选文字与页面缩放，兼容独立窗口安全区布局。浏览器无法保存时会明确提示，当前会话仍可玩。

## 素材与部署

场景为项目绘制的 SVG，字形配方、拼音、短释义和关卡提示为项目编写。笔顺原始资料来自 Hanzi Writer Data（固定提交 `68d10a4b21150cae5e1ebbd223eed289cf32d90c`），上游为 Make Me a Hanzi 和 Arphic Technology 字体，按 Arphic Public License 分发。原笔画路径和中线未修改；子集聚合说明写在 `glyph-strokes.json`，原许可 `ARPHICPL.TXT` 随站点及原生资源一起分发。

`data/static-assets.json` 是 Vercel、IGA 与原生资源的共同清单，当前 20 个文件。`.mjs` 在打包时改为 `.js` 并同步修改相对导入，避免静态平台 MIME 问题。笔顺 JSON 按需读取，不增加塔防主页面的笔顺下载。

## 验证

- `node --test tests/*.test.mjs`：328 项规则，包含所有关卡/配方/笔画、存档校验、塔防旧模块哈希。
- `node tests/glyph.cjs`：Chromium 四尺寸；`BROWSER=webkit` 运行 WebKit。包括两个浏览器各实际走完 20 关、逐笔描写清、拖拽、包围与三叠布局、关后探索、正常动画、载入失败重试、保存被禁用及旧战局隔离。
- `python3 scripts/build-glyph-strokes.py --check`：与固定上游数据比较。
- `node scripts/audit-glyph-mode.mjs --write`：生成[内容与资源报告](reports/glyph-mode.json)。

WebKit 检查模拟 iOS 独立窗口，不替代实体 iPhone 或儿童实际使用反馈。此次塔防三个核心模块没有变化，没有重新运行原有 400 局平衡模拟。
