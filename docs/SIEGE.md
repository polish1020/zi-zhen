# 沿途攻塔、守备与修缮

94 种怪物全部有攻塔配置，十四类词塔全部有守备职责。怪物沿原路线前进，在射程内选择目标，显示蓄力连线后命中；蓄力期间减速行进，不绕路追塔，也不因废墟永久停住。不设同时攻击人数上限；同优先级目标优先分散，近距石系承伤和潜行猎手的辅助目标偏好保留。每只怪都有独立前摇与冷却，首击略微错峰。密集围攻改用伤害递减，不再让大多数怪物空等。

## 怪物分工

| 类型 | 攻塔职责与应对 |
| --- | --- |
| 普通与快速兵 | 近袭、突袭；快兵单次伤害低，不能同时当高速与高攻拆塔兵。 |
| 甲兵、巨兽、机关 | 撞击或破阵重击，可扫及 110 距离内另一座塔，副伤害 45%；分散布置和石系承伤。 |
| 飞行兵 | 按空中路线掠袭，能接触地面路线以外的后排；用弓、雷与控制拦截。 |
| 潜行、影皇系 | 优先袭击射程内的光/金辅助，未被照明或咒印时偷袭增强；近距石系和守阵塔可以接走目标。 |
| 护阵、书灵、星灵等法术兵 | 远程墨弹；缄默或冰冻可打断蓄力，后排也需要保护。 |
| 腐蚀虫与对应 Boss | 命中削减护甲 4 秒；修复可清除状态。 |
| 冰壳兵与对应 Boss | 命中冰滞，词塔攻击间隔增加 15%，寒霜塔只增加 8%；不与寒域和干扰相乘。 |
| 赤焰兵与对应 Boss | 焰击；火塔对此减伤 30%。 |
| Boss | 按空袭、法术、影袭、重击分工，原有主动技能和半血机制保留，狂化后的攻塔也增强。 |

攻塔伤害使用缓慢成长系数，独立于敌人生命增长。前三轮有伤害缓冲；任何单次命中最多扣除词塔最大耐久的 22%。冰冻可打断所有蓄力，缄默只阻止法术攻塔。离开范围、死亡、目标拆除或损毁都会取消无效命中。预警、冷却与围攻目标随战局保存。

## 十四类词塔

| 属性 | 守备职责 |
| --- | --- |
| 文 | 耐久较稳，轮末额外自修 5%。 |
| 火 | 受击限频反灼，抵抗焰击。 |
| 冰 | 受击限频减速敌人，更耐冰滞；冰壳仍免控。 |
| 雷 | 电击延后攻塔读条，同目标最多每秒一次。 |
| 风 | 轻灵，常驻 10% 护甲。 |
| 石 | 高耐久、20% 护甲，近距优先承伤。 |
| 光 | 覆盖友塔减伤 12%—15%，增加轮末修复。 |
| 毒 | 受击限频反毒，毒伤继续抑制敌人回复。 |
| 弓 | 耐久较低，以长射程换安全站位。 |
| 金 | 降低范围内存活塔的修复费 15%；不打折重建。 |
| 剑 | 较高耐久、12% 护甲、限频剑气反击，反击可被护盾吸收。 |
| 水 | 命中的敌人 2.5 秒内攻塔伤害降低 15%。 |
| 咒 | 被咒印标记者攻塔伤害降低 10%。 |
| 幻 | 攻击本塔的蓄力延长 0.18 秒。 |

耐久同时取决于原词品质、升级、攻击形态与附加词义。守阵、重击、龙息更坚固，远射更依赖距离；成长词义提高升级耐久，护佑增加护甲，研习降低修复费，救险对危急词塔修复有优惠，回春可协助邻塔轮末修复。原有 0/1/1/2 词义上限、攻击机制和两次升级仍保留。所有词都按这套组合生成守备属性，近义词可共享职责。

## 损毁与经济

- 耐久归零后留在原阵位成为废墟，暂停攻击、光环、产墨、山门保护和新被动；已施加的持续伤害及短暂区域自然到期。
- 废墟保留词语、等级和历史投入，付费重建不再次消耗字牌。升级需要先恢复；升级增加当前和最大耐久的相同差值，不抹去原伤势。
- 手动修复填满耐久、清除腐蚀和冰滞，修复/重建冷却 8 秒；暂停可以操作，冷却随游戏时间冻结。
- 存活塔修复费为原投入的 18% × 损伤比例，至少 3 墨点；再应用金塔、研习和救险优惠。废墟首次重建为原投入的 50%，同塔以后每次增加 15 个百分点，依次为 65%/80%/95%/100%，100% 封顶，不享这些优惠。重建次数跨轮和无尽保留；日常修复不增加次数，新建塔重新计数。
- 修缮费用不增加原投入。存活塔拆除返还原投入 70%，废墟返还 35%，重建再拆除不制造利润。
- 每轮末对存活塔免费恢复最大耐久 30%；附近光系/回春加 10%，文系自修另加 5%。不免费复活废墟，轮末解除攻塔减益并允许整备维修。
- 主线前三轮普通怪掉落完整，第 4 轮 95%、第 5 轮起 90%。清波/轮末基础奖励仍在第 6 轮封顶，Boss、财塔及额外赏金保持完整；无尽继续完整基础掉落。用实际修缮消费替代一部分纯收入压缩，保留原定提示涨价与固定 50 换字。

旧存档词塔以满耐久接入新系统，已有墨点和投入保留。保存的非法负值或非数值会拒绝；将来耐久上限调整时会把旧有效耐久限制到当前上限，不因此抹掉整局进度。

## 测试口径

规则与因果回归 188 项通过，含所有词和 94 个攻塔配置、真实地图双塔范围重击、打断、目标消失、全员围攻与伤害递减、废墟停止被动、维修扣费与重建、升级伤势、光/金保护、元素反应、保存/迁移。

当前 400 场真实资源主线仿真，技能/无技能策略都包含维修，结果见 `TESTING.md`。此前在重建固定 40% 的版本另做 100 场维护审计及同初始种子 50 场禁用手动修复的对照，记录实际维护支出、受击与损毁；没有注入墨点、字牌或击杀。自动策略不是玩家胜率；这份维护审计为历史基准，不能当作当前重建费用账本。历史数据摘要见 [siege-summary.json](reports/siege-summary.json)。

Chromium 与 WebKit 覆盖 320×568、393×852、667×375、1440×1000，验证真实攻击损毁、暂停修复/重建、词语和字牌保留、94 类图鉴攻塔说明、重载及三按钮同屏。还回归十尺寸响应式、基本流程、暂停、词义品质、94 张图鉴和组合攻击渲染；WebKit 模拟不替代实体 iPhone 测试。

## 全员围攻与主题攻击

- 94 种怪物均可在十张地图的合法位置命中，包括 52 小怪、42 Boss。小墨点射程由 65 补足为 80，避免部分地图最近塔位也够不到。
- 统计可触及此塔、正在蓄力或收招的附近敌人 N。两名以内伤害完整；更多敌人时普通怪乘 `(2 + 0.35 × log2(N / 2)) / N`，Boss 乘此数的平方根。所有攻击仍造成真实正伤害，总压力缓慢增加；单次 22% 最大耐久上限和前三轮缓冲保留。
- 重击副目标 45%；雷击可连及邻塔 30%，潮汐 25%。副目标仍需在武器射程内，距离限制分别为 110/100/100。冰系命中造成 2.5 秒冰滞、腐蚀系削甲 4 秒；火系焰击由火塔抵抗 30%。机关以更长前摇和冷却换射程；竹灵、树祖、墨王和蛊后等按自身特性使用远程施法。
- 十六类表现为爪击、突刺、震地、空袭、影刃、墨弹、烈焰、冰晶、腐液、雷霆、潮汐、根须、碎镜、符印、星芒与机括炮击。相近怪物共享基本招式，结合各自外观、元素、射程、冷却和既有技能体现区别。
- 蓄力目标环与群袭数只画一次，每只怪保留起手和命中表现；0.18 秒内同塔耐久数字合并，避免大量文字遮挡。Boss 招式名贴随本体，未添加独立 HUD 或大血条。主动技能的治疗、凝盾、孵化、战吼和跃迁另有相应图形。

全员攻塔初版的两策略 88.5% 结果见历史 `reports/enemy-attacks-summary.json`。当前词库、Boss 和递增重建版，400 场主线仿真通关率为无技能 96.5%、使用技能 97.5%，每章 20 个种子均通过原有检查标准。它验证自动布阵策略能承担真实维护费用，不代表真人胜率或后期墨点不积累。详见 `TESTING.md` 与 `reports/vocabulary-balance-summary.json`。

## 本轮 Boss 强化与兼容

全部 Boss 在原有逐轮曲线上生命乘 1.15，沿途攻塔基础伤害乘 1.25，攻击间隔乘 0.8，且保留至少前摇加 0.8 秒的收招空间。既有主动技能、半血阶段、群袭递减、前三轮缓冲和单次伤害上限保留。首击按敌人编号略微错峰；不是同时排队等待两个攻击位。旧存档在场敌人保留已保存生命，新生成敌人使用新生命倍率。旧词塔没有重建计数时从首次 50% 开始，不追扣费用。非法计数拒绝载入。
