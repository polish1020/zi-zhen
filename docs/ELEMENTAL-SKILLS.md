# 元素组合与灵兽技能词

新增 4,851 个明确列入规则的游戏技能词，运行词表为 112,468 词；共 14,881 个技能词。包括截图中的「冰雷斩」，以及火麒麟、冰火剑、雷火刀、风雷箭、寒冰凤凰、雷霆白虎等。

新增词由 40 组双元素词根、现有技能后缀、14 类新增后缀和 16 类灵兽组合生成，最长四字。双元素技能 3,144 词，单元素扩充后缀 523 词，元素灵兽 1,184 词；按长度为二字 73、三字 1,517、四字 3,261。相近组合使用现有机制，不是数千套独占招式，也不标成成语。

| 示例 | 实际属性、形态及效果 |
|---|---|
| 冰火剑 | 寒霜锋刃，减速主目标，命中附加灼烧 |
| 冰雷斩 | 雷霆锋刃，雷击连锁，主目标附带凝霜减速 |
| 雷火斩 | 雷霆锋刃，连锁雷击并灼烧主目标 |
| 火麒麟 | 烈焰重击，每第三次攻击追加一次 20% 直接伤害的灵伴追击 |
| 烈焰麒麟 | 四字品质，灵伴追击之外保留灼热附加特性 |
| 冰火麒麟 | 寒霜重击，附加灼热与灵伴 |
| 雷冰剑阵 | 雷霆守阵，带凝霜与护佑附加特性 |
| 寒冰连斩 | 寒霜连击，保留凝霜与锐意附加特性 |

双元素由基础属性与实际生效的附加特性共同表达，不能同时得到两套完整基础属性。三字最多一个附加槽、四字最多两个，仍受原有品质限制。兵器取锋刃/远射/连击，剑阵取守阵，麒麟取重击，凤凰/朱雀取弥散，龙类取吐息，白虎取锋刃，玄武取守阵。灵兽使用灵伴追击；各形态、属性和附加特性的已有视觉表现继续生效。

## 数据与存档

`data/elemental-skills.json` 明确限定词根、后缀及其效果。不会按任意字符串猜测新词；桌子麒麟、桌子斩、斩雷冰及超过四字的冰雷斩击术都不能组成。按词序匹配、一张牌只能用一次、墨点扣费及所有价格保持。

生成器保留 27 个与现有词重合的条目，例如冰火箭、冰火双刃和火凤凰，避免覆盖原词义配置。原有全部 107,617 个词的完整配置逐项哈希均相同；没有重新分类既有成语、普通词或文化释义，也没有新增存档版本。旧手牌在重载后可以直接识别新词，已用字牌、受伤词塔、等级和投入保持。

新词随原技能池进入开局和付费刷新，不额外默认提示。2,000 批手牌均满足三个不同二字、两个不同三字和一个四字保底；平均候选二/三/四字为 23.83 / 15.12 / 4.97，交叉候选可能共用字，不能把候选数当成可同时落塔数。

## 验证与平衡

308 项规则通过，新增全量 4,851 词的类型、词序、元素/灵伴槽位、所有旧配置完整哈希、例词真实扣牌扣费/读档、冰火减速灼烧、冰雷连锁及主目标减速、火麒麟第三击真实增伤、自然发牌覆盖。原远射测试继续核对冻结的全部旧词，新增词由新审计单独覆盖。

Chromium / WebKit 的 320×568、393×852、667×375、1440×1000 验证截图原词、词义标签、四个新词实际落塔、13 张字牌逐次消费、精确扣费、技能词典、三倍速实战中的减速/灼烧/灵伴、暂停重载、50 墨点换牌及最长词付费提示/免费复看，无脚本错误或页面溢出。WebKit 模拟独立窗口不能代替实体 iPhone。

十章种子 1—20，沿用两种自动布阵策略（不开/开启落墨），实际资源与价格，无额外注资；400 局 272 胜（68%），两策略各 136/200，均无超时。上次完整测试为 74.5%。各章为 90% / 70% / 75% / 87.5% / 100% / 80% / 40% / 45% / 77.5% / 15%。第 5 章仍偏容易，末章偏难，整体没有达到严格逐章递增或原先 50—60% 偏好，没有按胜率配额改怪物、词塔、价格或策略。

两策略共用 20 个种子，不能当成四十张独立地图，更不是小朋友实玩胜率。扩大词池会改变发牌选择及后续 RNG，因此不能把同种子结果理解成固定敌阵的独立因果对照。前次完整战斗报告来自镜城路线版本，随后一版仅增加了 Boss 战败表现；本报告保留两者提交和源码哈希以区分。
