# 移动端封装准备

已准备开始界面、竖屏地图/字库上下同屏、短横屏左右并列、地图等比绘制和触控适配、安全区域、动态视口、后台自动暂停、完整随机状态存档和本地资源。网页不依赖远程字体；游戏可以使用本地 WebView 资源运行。

## 本地资源包

```sh
python3 scripts/prepare-mobile.py
```

输出为 `mobile/www/`，包含 HTML、三个 CSS、三个 JavaScript 模块（含本地词库）、图标、Web App Manifest 与第三方许可声明。`.mjs` 适配为 `.js`，HTML 与 import 引用一并改写。生成目录不提交。可以先用静态服务器预览该目录。

根目录的 `capacitor.config.json` 指定：

- 应用 ID：`com.polishwb.wordward`，发布前可按主体需要调整。
- 应用名：字阵。
- Web 资源目录：`mobile/www`。
- iOS 内容边距：由界面自己的安全区域处理。
- 未配置远程服务器地址，正式封装应加载随应用安装的本地资源。

后续选择同一主版本的 Capacitor Core、CLI、Android / iOS 平台包，再添加对应原生工程、同步资源，用 Android Studio / Xcode 构建。当前未安装原生 SDK、未生成 Android / iOS 工程、签名或安装包。

## 封装时仍需完成

确认正式应用 ID、开发者主体和目标平台；生成各平台启动图及应用图标；在真机上检查刘海/底部手势区、系统返回、后台恢复、音频中断和 WebView 存储持久化；完成签名、商店资料及审核。Web App Manifest 用于浏览器独立启动配置，不代表已经完成原生打包或浏览器离线缓存。

网页域名和原生 App 属于不同的存储空间，网页存档不会自动出现在原生应用里。引擎已有可迁移的序列化格式；若需要跨端转移，应在后续增加导出/导入或同步功能。
