# 四字普词复查与生肖、龙类补词

基线为 Git 提交 `183f9df`：此前“已识别成语中的普为零”并未检查全部普通四字词，因此漏掉一专多能等词。本次展开阅读全部 4,088 个词头，逐项记录改类或保留结果；不是每条均做独立字典出处考证。

- 改类 703 词：248 个成语、450 个常用四字短语或文化词、5 个已有技能词。
- 保留 3385 个普词，包括专名、技术术语、普通技能词和未确认的短语/残句；没有为了清零把所有四字词改成成语。
- 每个改类词复用符合整体含义的既有招式与绝技；仍为 80 类学核心和 39 类绝技，没有新一轮全局基础数值增强。
- 补写 38 条简明释义。修改名单、词类和招式是项目维护的数据，不受外部词典是否收录的限制。
