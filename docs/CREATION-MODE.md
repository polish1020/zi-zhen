# 自由造物

`/glyph.html` 为当前默认造字模式，与首页的组词守关并列。从空白画卷开始，没有任务顺序、付费提示、倒计时或失败惩罚。

## 组字、组词、落笔

329 个字、249 种部件、304 个可造景字词，其中 166 个为二至四字词。全部部件和配方开放，可按部件名、字形、拼音或字义搜索。每次推荐包含至少三个完整配方所需的部件，也保留人、木、水、雨等入门字；刷新不收费、不删除已认识的字。

先选整字、左右、上下、包围或三叠摆法，按位置放部件。整字栏不等于独体字分类；对结构不够确定的复杂字保留整体，避免编造拆法。字形配方参照现代简化字，部件不一定都是部首。未知组合只提示暂未收录。

造出的字收进字袋，可以直接反复落笔，也可以继续按词序组二至四字词。不是所有单字都具备造景效果；抽象的字仍能读释义、收入字袋、参与组词。造物册会标明哪些字词能够落笔，哪些字还需要先造出来。普通四字词不会自动标为成语。

例子：木＋木→林；三个木→森；森＋林→森林；雨＋田→雷；火＋山→火山；雪＋山→雪山。春暖花开融化冰雪并让已有植物开花；风和日丽让画卷放晴并吹风；鸟语花香添花与鸣鸟；山清水秀清洁画中水域、增添绿意。

## 自由画卷与相遇

造物可以拖动、换样、调大小、移开；落笔、天气、移动、改名与外形变化都能撤销，最多保留 24 步。认识的字、已组出的词和见过的相遇不会因撤销丢失。

- 雨水促生长、熄灭画中的火；人物会靠近屋子避雨或撑伞。
- 雨后放晴可见彩虹；月、星和灯火一起形成夜景。
- 水是鱼、船、荷花的前提；水移动时带着附着的造物。最后一汪水仍有依赖者时会提示先移开它们。
- 冰雪让水结冰，温暖让冰雪消融；高山近水可形成瀑布。
- 鸟停树枝，人在树旁休息，花丛与蝴蝶、蜜蜂相遇，风车遇风转动。
- 花丛、树林或雨中的水生环境有机会引来蝴蝶、小鸟、青蛙。概率由保存的随机种子控制，不伤害或替换玩家造物，撤销后重试保留结果。

17 类相遇只记录见过的现象，不作为必须完成的任务。景物由项目手绘 SVG 构成，按家族复用轮廓；同一物体允许外形、颜色和大小变化，并非每个词都独占一套图形。

## 保存和设备

独立存档 `wordward-creation-save-v1` 包含当前画、已认识字词、相遇、随机状态和最多 8 幅旧画。开新卷会先收入旧画，可随时交换回来继续添画。删除旧画需明确二次操作；清空浏览器会丢失本地画册，没有云同步。

首次创建自由画卷可读取旧 `wordward-glyph-save-v1` 中的已认识字，之后互不改写。旧练字小径保留在 `/glyph-lessons.html`，配音关闭，描红仍可用。原塔防的战斗引擎、词库、技能模块没有变化。离开时自动保存，禁止存储时明确提示未保存并允许当次游玩。

手机竖屏为上方画卷、下方造物台；横屏左右布局，桌面为大画卷和侧边工坊。玩耍界面不需要整页滚动，字库和画册在弹窗中滚动。独立窗口使用安全区和真实可用高度；WebKit 自动化不代替实体 iPhone 验证。

可导出独立 SVG 图片，图中包含当前景物、天气和题名，不依赖网络图片；图片不包含可继续编辑的存档，不能当作存档备份。新玩法不调用语音合成、麦克风或外部 AI 接口。
